# dmg installer assets

this folder contains the dmg installer window assets and generator. visual references were exported from figma:

`https://www.figma.com/design/zRe1li9DBtBHKongnfJUgE/macos-menubar-app?node-id=2001-1206`

files:

- `assets/figma-reference.png`: 540x340 figma reference export.
- `assets/figma-arrow.svg`: exported arrow vector.
- `assets/figma-appicon.svg`: exported app icon asset.
- `generated/dmg-background.png`: finder background generated by `generate-background.py`.
- `generated/dmg-background@2x.png`: retina-sized version.
- `create-dmg.sh`: builds `Artifacts/OnePlus-Buds-Menu.dmg` with app icon on the left and `/Applications` alias on the right.

usage:

```sh
Packaging/DMG/create-dmg.sh
```

or pass a specific app bundle:

```sh
Packaging/DMG/create-dmg.sh "/path/to/OnePlus Buds Menu.app"
```

for a signed and notarized github release, run `Packaging/release.sh` from the repository root.
